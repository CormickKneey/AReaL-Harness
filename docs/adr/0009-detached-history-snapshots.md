# 采用目标自持有的不可变历史快照

决策标识：SCF-ADR02 · 状态：proposed

历史可能跨冷段、摘要和多模态引用，简单复制热 turns 不能保证指定 Turn 的边界。决定在创建时提取并物化所选逻辑前缀，目标持有快照，Fork 将其作为独立继承历史块，Side 将其作为引用证据。第一版接受创建时有界 I/O 成本，换取来源变化、归档和恢复下可验证的一致性。

源码已在开发开关下实现，契约见[桌面 API](../api/desktop.md#turn-fork-开发预览)。原生桌面与完整 P0 验收仍待完成，因此决策保持 proposed；局部源码验证不能替代这些验收结果。

## 权衡与后果

不采用客户端复制消息，也不立即建设共享可变父链或通用分支 DAG。内容寻址字节仍可复用，但不得让目标依赖来源最新状态。旧 checkpoint 不直接继承，必要的摘要从精确原始前缀重建；GC 必须认识快照引用。

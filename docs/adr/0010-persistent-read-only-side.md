# Side 默认持久化并维持不可变只读角色

决策标识：SCF-ADR03 · 状态：proposed

旁路会产生值得保留的判断，而窗口关闭和 Core 执行具有不同生命周期。决定首问受理时持久化 Side，关闭仅隐藏；Side 的只读角色由 Core/Runtime 保证且恢复后保持。增加存储和列表管理成本，避免临时窗口丢失讨论，以及借旧客户端或重启获得写权限。

## 权衡与后果

拒绝默认临时会话和仅靠提示词限制写操作。P0 不提供原地升权、删除或 TTL；未发送草稿仍遵循现有 GUI 进程内语义。持久权限角色要求数据版本门禁，旧二进制不能忽略它继续运行。

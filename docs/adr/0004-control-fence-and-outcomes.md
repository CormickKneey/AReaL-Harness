# 人工控制栅栏优先，结果不明不自动重放

**状态：proposed（设计提案，尚未实施）**

人类接管与跨进程动作可能并发。Browser Controller 先增加控制代次并拒绝旧代次输入，再通知 Core；这比等待远端审批更能保证可接管性。Core 仍是审批与历史权威，已可能派发的动作沿用 UNKNOWN 语义，不因本地接管或重连而改写成失败或成功。

## 考虑的方案

仅暂停模型循环不能停止队列和在途 CDP；取消 RPC 也不等于撤销网页副作用。试图提供端到端 exactly-once 会给支付或表单提交造成虚假保证。

## 后果

人工控制时自动观察、截图及诊断同样暂停。继续需要新控制授权与观察。存在 UNKNOWN 时必须核对并使用既有检查确认流程；日志保留未知原貌。每一步批量动作都检查栅栏。

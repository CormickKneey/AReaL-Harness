# Fork 对话前缀与文件状态明确分开

决策标识：SCF-ADR04 · 状态：proposed

用户选择过去的 Turn 容易误以为代码也回到当时版本，但当前系统没有与每个 Turn 一一对应的完整工作区快照。决定 P0 仅分支对话，明确选择并显示当前共享工作区，不触发 Git reset、stash 或隐式 worktree。代价是无法安全宣称两条分支具有并发写隔离。

## 权衡与后果

完整文件快照及隔离 worktree 是另一项能力，延后设计；检查来源空闲不能替代工作区互斥。历史工具观察不证明当前文件未改变，模型和 UI 都必须知道这一点。

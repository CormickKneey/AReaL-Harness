# ActivityGroup 活动分组

## 何时使用

`R-ACTIVITYGROUP-001` 同一轮、同一项目内连续工具活动的按需阅读；单条活动用presentation=inline直接呈现；数量增长后切回collapsible，保持同一实例和子记录身份。不要跨用户消息、助手说明或最终回答合并。

## 组成

`R-ACTIVITYGROUP-002` 具名摘要、可聚焦的有界滚动区、折叠外的 status 插槽。children 保留原顺序，实际分组与事件身份归宿主投影。

`R-ACTIVITYGROUP-032` 活动行、活动组摘要、图片入口与子代理行共用对话节奏：每行高度为一行对话文字（`--text-conversation` × `--conversation-line`），相邻块之间隔 `--conversation-gap`，与正文段落一致。摘要不加底色，展开与否只由箭头方向表达；箭头在悬停、键盘焦点或展开时出现。展开的同类分组中，子项与摘要文字左对齐、彼此间隔 `--spacing-inline`，类型已由摘要图标说明，子项不重复行首图标。文件名不加常驻下划线，悬停时才提示可打开。

`R-ACTIVITYGROUP-033` 行首图标统一为 16px、约 1.05 线宽的活动图形集（`ActivityIcon`），箭头 14px：读取、编辑、搜索、列出、命令来自 Codex 采样；图片、浏览器、等待与通用工具为按同一网格补齐的图形。没有语义类别的插件或 MCP 工具使用通用工具图形，保持文字起点对齐，名称仍显示真实工具名。

## 状态

`R-ACTIVITYGROUP-003` 默认收起；手动选择在同一实例中保留。父组收起保留子详情，追加输出或完成不重置展开。失败、审批和 UNKNOWN 在 status 中可发现。

## 行为

`R-ACTIVITYGROUP-004` 列表只纵向滚动，摘要不随列表滚走。长命令/代码/路径换行；完整复制由原阅读器负责。展开或查看不会执行、重试或归并不同命令。

## 内容

`R-ACTIVITYGROUP-005` 摘要使用真实类型和数量；未知计数就省略。模型过程摘要使用 [ThinkingStatus](../thinking-status/thinking-status.md)，不替代执行结果。

## 可访问性

`R-ACTIVITYGROUP-006` 沿 Disclosure 键盘语义；滚动区可聚焦。条目必须有可理解名称和合法动作，不能只裁切正文来消除横向滚动。

## 规则

`R-ACTIVITYGROUP-007` 使用原事件 ID 作 key；对象切换重建，状态更新保持身份。高度上限是组件局部选择，不登记全局 Token。

## 主阅读列与活动层级

| 层级 | 内容 | 默认呈现与用途 |
| --- | --- | --- |
| `R-ACTIVITYGROUP-009` 会话正文 | 用户消息、助手过程说明、最终回答 | 保留独立身份、顺序与完整阅读能力；正文不因附近工具增加而变成命令输出 |
| `R-ACTIVITYGROUP-010` 过程总组 | 本轮过程文字与常规活动 | 沿 CONV-GROUP-01：正常结算且 final 明确后可收敛；仍运行、待决定、失败与未知保持可发现 |
| `R-ACTIVITYGROUP-011` 活动组 ActivityGroup | 同一轮、同一段连续工具活动 | 用户要求默认收起；露出类型摘要、数量和必要状态。手动展开后显示有序活动列表 |
| `R-ACTIVITYGROUP-012` 活动行 ActivityRow | 读取、命令、编辑、图片或子代理的一条事实 | 类型图标 + 动词/对象 + 必要状态 + 明确动作；保持轻量，不把每一行绘成卡片 |
| 活动详情 | 原命令与输出、读取记录、变更、图片或原始回执 | 用户按需展开或打开原资源阅读器；同一对象的不同动作有独立入口 |

`R-ACTIVITYGROUP-013` 这是可用的层级，不要求每条活动都套满五层。单条活动直接使用活动行；不为了做组而额外包一个同名标题。

`R-ACTIVITYGROUP-014` 分组使用原有事件身份与连续顺序：不跨用户消息、助手说明或最终回答合并，不把不同轮次或不同项目的活动混在一起。同一进程的输出读取沿 processId 归并为一条命令记录，不增加“执行次数”。图片和子代理使用各自变体，不因邻近命令而失去类型与入口。

### 活动行的有限变体

| 变体 | 收起时回答什么 | 展开或主要动作 | 内容边界 |
| --- | --- | --- | --- |
| `R-ACTIVITYGROUP-015` Read / 读取 | 读取了哪个文件；多项可摘要为“读取文件” | 打开文件；独立入口查看该次读取记录 | 文件当前内容与当时读取回执不同，必须保留来源区别 |
| `R-ACTIVITYGROUP-016` Command / 运行命令 | 执行了哪条命令，当前运行/退出情况 | 展开原命令、工作目录、输出、退出码及收集状态 | 工具返回不等于进程退出；查看与复制不会重跑 |
| Edit / 编辑 | 修改了哪个文件；有可信回执时显示本次增删 | 查看本次差异或文件；原始记录次一级 | “已编辑文件、运行命令”是混合活动摘要，不是编辑已执行命令的操作 |
| `R-ACTIVITYGROUP-017` Image / 查看图片 | “已查看图片”及数量或可识别名称 | 用户要求图片内容默认关闭；手动展开缩略图后可进入原图片查看器 | 这是工具活动图片的规则。用户输入附件与最终交付图片仍按自身内容合同呈现 |
| `R-ACTIVITYGROUP-018` Subagent / 子代理 | 可识别的任务名称与独立状态 | 打开该子对话；创建回执可另查 | 创建成功、子任务完成、父任务完成是三种事实；不从模型自述生成完成状态 |
| `R-ACTIVITYGROUP-019` Stage / 阶段段 | 该工作阶段的动词与已完成计数，如“已探索 · 3 个文件，2 次搜索”；失败数在同一标题内写出 | 展开原顺序活动，子项保留各自类型与结果 | 按工具身份归入阶段（见 Messages `CONV-ACTIVITY-01`），不解析 shell 文本猜测读写权限；计数只取已完成子项 |

`R-ACTIVITYGROUP-020` 活动名称描述真实动作。运行中使用“正在运行”，完成后使用“已运行”；失败、未知、仍在收集输出分别保留。没有准确计数或耗时就省略，不制造百分比。图标辅助识别，文本承担含义。

### 折叠与状态

| 对象/条件 | 默认 | 人工操作与后续增量 |
| --- | --- | --- |
| `R-ACTIVITYGROUP-021` 常规活动组与命令详情 | 收起；当前活动与必要状态在摘要可见 | 打开后保持同组选择，追加输出与完成事件不强制关闭 |
| `R-ACTIVITYGROUP-022` 工具活动图片 | 图片内容收起，保留具名入口 | 选择展开后保留选择；加载失败在该入口附近反馈 |
| `R-ACTIVITYGROUP-023` 正常完成的过程总组 | 沿原合同收敛，final 独立 | 不覆盖同身份的人工展开；不把父组收起当作清空子项选择 |
| `R-ACTIVITYGROUP-024` 待审批、失败、UNKNOWN、未结算 | 状态与合法入口在收起摘要外层仍可发现 | 关键决定不能藏在待展开的日志里；用户仍可收起详情，无需强制打开全部输出 |
| `R-ACTIVITYGROUP-025` 切换项目/会话/轮次 | 读取该对象自身的默认或选择 | 不继承另一对象的展开状态；跨应用重启保存展开值不是本轮要求 |

`R-ACTIVITYGROUP-026` 活动组收起不等于停止执行。展开、复制、查看全部、打开子任务与返回均是阅读动作，不提交、重试或恢复未知写入。

### 溢出与滚动

`R-ACTIVITYGROUP-027` 用户要求活动组只纵向滚动。展开后列表有界增长，超过所属容器的阅读上限才出现纵向滚动；摘要留在滚动列表之外。具体高度随容器与字号验证后由原组件负责，不从截图取一个固定全局值。

- `R-ACTIVITYGROUP-028` 活动摘要可截断，展开详情必须能读全。长命令、路径、URL 和无空格输出在可用宽度换行；复制保留原始字符与换行。
- `R-ACTIVITYGROUP-029` 不能仅隐藏横向滚动条而裁掉内容。活动列表及其内嵌命令正文不产生横向滚动，也不撑宽主聊天。
- `R-ACTIVITYGROUP-030` 长命令/输出按需进入既有详情区域，避免在活动组内再套多层独立纵向滚动。完整 Diff、图片缩放与专用阅读器按原资源合同处理；命令组规则不取消这些阅读器的必要平移。
- `R-ACTIVITYGROUP-031` 每个区域只有一个滚动所有者。内层到边界后的滚动行为由原宿主核验，不用脚本把主聊天拖回最新；展开与折叠继续保留阅读锚点。

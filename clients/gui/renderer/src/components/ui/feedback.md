# Feedback 反馈

## 用途

在所属组件附近显示操作错误或状态说明。保留用户正在查看的对象和输入。

## 不适用

反馈文字不承担动作入口，不替代审批、恢复和结果核对。需要用户决定时使用所属流程的交互控件。

## 状态

有 `error` 时显示 `alert`，否则有 `message` 时显示 `status`，两者均为空时不渲染。Props 与实现以 [feedback.tsx](./feedback.tsx) 为准。明确失败与结果待核对使用不同事实描述。

## 键盘与焦点

反馈本身不进入 Tab 顺序，也不主动移动焦点。调用方保留原操作位置，必要动作使用独立且有名称的按钮。

## 禁用

反馈没有禁用状态。所属动作不可用时，说明原因并保留反馈可读。

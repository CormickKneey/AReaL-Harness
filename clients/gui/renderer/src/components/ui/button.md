# Button 按钮

## 用途

发出一次动作或打开入口。按钮文字说明动作，纯图标按钮由调用方提供可读名称。

## 不适用

持续状态的开启与关闭使用 [Switch](switch.md)。在候选值中选择使用 [Select](select.md)。紧凑设置操作使用 [ActionButton](action-button.md)。

## 状态

默认、悬停、键盘焦点、禁用和无效状态由按钮样式表达。外观不证明业务操作已经受理或完成。Props 与可用外观以 [button.tsx](./button.tsx) 为准。

## 键盘与焦点

使用 Tab 进入可用按钮，按 Enter 或空格触发。键盘焦点保留可见轮廓。弹窗关闭后的焦点返回由调用方处理。

## 禁用

禁用按钮不能触发动作。调用方根据真实可用条件传入禁用状态，并在所属区域说明原因。

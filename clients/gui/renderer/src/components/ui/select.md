# Select 单值选择

## 用途

从多个候选中选择一个值。触发按钮展示当前值，展开后展示候选与选中标记。

## 不适用

`R-SELECT-003` 执行一次操作使用 [ActionButton](action-button.md)。开启或关闭使用 [Switch](switch.md)。流程步骤和导航入口不使用值选择语义。

## 状态

`R-SELECT-004` 触发按钮区分默认、展开、焦点、禁用与无效状态。选项区分选中、键盘高亮和禁用状态。Props、组合成员和弹层实现以 [select.tsx](./select.tsx) 为准。

## 键盘与焦点

使用 Tab 进入触发按钮，按 Enter 展开。使用方向键移动，按 Enter 选择，按 Escape 关闭。组件管理弹层与键盘焦点，调用方提供可读标签。

## 禁用

`R-SELECT-005` 不可用的触发按钮或选项不能用于改变值。调用方保留当前值，不以占位文字冒充已选择。

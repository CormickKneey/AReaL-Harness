# D-002 共享语义先于统一数值与实现

已采用共享浏览器焦点默认值，其他角色仍按实际消费者选择。

图形界面、终端与机器输出共享用户意图和状态含义。它们保留适合本端的交互、几何和能力映射。当前已有不同的生产主题源，直接复制 GUI 数值会掩盖差异。先建立 [Token 映射](../foundations/tokens.md)，再按实际消费者选择共享默认值子集。复核条件是同一默认值已被多个消费者确认，并需要共同版本和漂移检查。

首组将焦点宽度与偏移的既有默认值迁入 [focus.css](../tokens/focus.css)。GUI 直接导入，Core 编译时与本地 Web 样式拼接。两个消费者均使用 CSS，因此不增加 JSON 或生成器。颜色、选择器、批准控制器与动态偏好保留原所有者。扩大范围前另行核对真实消费者和平台能力。

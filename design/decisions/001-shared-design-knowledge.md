# D-001 GUI 优先，设计知识集中维护

`R-DECISION-001` 已采用。2026-10-22 更新建设范围，以 GUI 为准，Web 后续复用。

`R-DECISION-002` 设计系统先服务桌面 GUI 的完整体验。后续 Web 需要复用适用的原则、Token、组件和模式，因此设计知识仍集中在根目录 `design/`。独立目录不要求同时适配所有客户端，具体范围由[设计地图](../README.md)维护。

`R-DECISION-003` GUI 的组件、布局、平台行为和准入继续放在原所有者。设计知识按原则、基础、人机关系、模式、组件和决策分目录。分散的共同正文迁入对应主题，原文改为引用，GUI 规则 ID 和生成区块保留原所有者。Web 接入时补充浏览器适配与验证，不另建一套设计定义。

`R-DECISION-004` 代价是需要区分设计知识与 GUI 实现合同，并在 Web 接入时重新核对原生能力差异。复核条件是同一规则出现两个可编辑定义，或 Web 的真实复用需求与 GUI 基线发生冲突。

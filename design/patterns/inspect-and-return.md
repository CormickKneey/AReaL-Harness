# 深入查看与返回

先判断用户要快速核对、持续阅读还是编辑，再选择有界预览、显式展开或独立阅读区域。信息层级不能靠缩小字号、无提示裁切或嵌套滚动代替。

## 长内容与全文

短内容完整呈现，长内容保留明确的全文入口。折叠只改变展示，不截断存储、发送、复制或导出的原文。关键决策参数、正在编辑的输入和需要完整核对的内容保留专用机制，不为了统一外观隐藏必要信息。

展开后用户能继续阅读，收起后能找到原操作及上下文。正文之外的附件和动作保持可达。同一内容的人工选择按[过程阅读](task-progress.md)处理。

## 资源与返回

资源入口标明当前对象及所属任务，打开后保留回到原任务的路径。关闭查看后的草稿、阅读位置和合理焦点由宿主恢复。资源读取失败不遮蔽其他有效内容。查看与控制的区别见[委派与交接](../people-and-agents/delegation-and-handoff.md)，Side 内容回传见[上下文与依据](../people-and-agents/context-and-evidence.md)。

| 平台 | 实现所有者 | 应核对的结果 |
| --- | --- | --- |
| GUI 与 Remote | [长文本组件指南](../../clients/gui/DESIGN_SYSTEM.md#长文本统一采用渐进展示)、原资源宿主 | 全文可达、展开与收起、身份、返回、焦点及原生视图 |
| TUI | [展开与阅读](../../docs/design/tui.md#展开与阅读) | 稳定内容锚点、键盘切换、终端宽度变化和输入焦点 |
| 本地 Web | [界面所有者](../../clients/web/app.js) | 浏览器内的展开、导航和草稿，不据此推导原生窗口能力 |
| 非交互 CLI | [输出契约](../../docs/api/claude-cli.md) | 所选输出模式中的完整内容和身份，不要求面板或折叠 |

返回是否成功需要实际操作验证。宿主截图不替代独立原生视图的可见性和交互证据。
